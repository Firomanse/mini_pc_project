# Mini PC Project \[ru | [en](README.md)\]
Это мини-проект, в который программно эмулирует компьютер с небольшим числом команд процессора.

## Сборка и запуск
Для сборки и запуска проекта можно использовать:

- **Командную строку:** запустите скрипт `./build.sh`, а после, запустите собранную программу: `./mini_pc_project`
- **IDE:** скопируйте файлы проекта в свою среду разработки и запустите их там
- Другие способы сборки возможно появятся в будущем


## Дополнительная информация
### Аргументы командной строки

|      Аргумент      |              Описание              |
|--------------------|------------------------------------|
| `-h`, `--help`     | Показывает справочную информацию   |
| `-s`, `--start`    | Запускает эмулятор                 |
| `-l`, `--log`      | Запускает эмулятор с выводом лога  |
| `-d`, `--debug`    | Запускает и показывает дамп памяти |
| `-a`, `--assembly` | Запускает мини-ассемблер (miasm)   |

### Список инструкций процессора

| Opcode |    Инструкция     | Размер | Операции |
|--------|-------------------|--------|----------|
| `0000` | `halt`            | 4-bit  | r        |
| `0001` | `poweroff`        | 4-bit  | r        |
| `0010` | `not`             | 4-bit  | r-d      |
| `0011` | `swap?`           | ?      | ?        |
| `0100` | `?`               | ?      | ?        |
| `0101` | `?`               | ?      | ?        |
| `0110` | `set <8-bit cmd>` | 12-bit | r-ow     |
| `0111` | `write <addr>`    | 12-bit | r-w      |
| `1000` | `and <addr>`      | 12-bit | r-d      |
| `1001` | `or <addr>`       | 12-bit | r-d      |
| `1010` | `add <addr>`      | 12-bit | r-d      |
| `1011` | `sub <addr>`      | 12-bit | r-d      |
| `1100` | `jump <addr>`     | 12-bit | r-c      |
| `1101` | `jz <addr>`       | 12-bit | r-d-c    |
| `1110` | `get <addr>`      | 12-bit | r-w      |
| `1111` | `read <addr>`     | 12-bit | r        |

**Виды операций:**
- `r` - чтение
- `d` - работа с данными
- `w` - запись
- `ow` - внешняя запись
- `c` - работа с часами/программным потоком
